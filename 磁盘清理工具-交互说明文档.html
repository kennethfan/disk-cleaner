净盘 CleanDisk — macOS 磁盘清理工具交互说明文档

版本：v1.0 ｜ 更新日期：2026-10-29 ｜ 配套产物：磁盘清理工具-UI交互原型.html（交互式原型，本档描述其全部交互行为）

视觉基调：浅色 macOS 原生风（#f5f5f7 窗体 / 系统蓝 #0a84ff 主色 / SF 系字体栈）

一、产品定位与设计原则

产品定位：macOS 磁盘空间清理工具。核心价值是「看得见的信任感」——用户敢把删除操作交给它。

四条安全交互原则（贯穿全部流程）：

  1. 只读扫描 — 扫描阶段不修改任何文件，UI 在侧边栏与扫描页常驻提示
  2. 废纸篓语义 — 所有「清理」操作移入废纸篓而非直接删除；30 天内可恢复；磁盘可用空间在清空废纸篓前不会变化（数字如实反映，不做假释放）
  3. 二次确认 — 执行清理前列出完整清单与合计大小，明确告知后果与可恢复性
  4. 可逆性 — 清理完成后提供「撤销本次清理」入口，从废纸篓放回原位置

二、信息架构

窗口（macOS 红绿灯标题栏「净盘 CleanDisk」）
├── 侧边栏
│   ├── 磁盘信息卡（迷你环形图 + 磁盘名 + 可用/总容量）
│   ├── 空间管理
│   │   ├── 概览
│   │   ├── 清理建议（角标 = 分类数）
│   │   └── 大文件（角标 = 文件数）
│   └── 安全
│       ├── 排除列表（角标 = 规则数）
│       └── 安全承诺文案（只读 / 废纸篓 / 二次确认）
└── 主内容区（随导航切换的 5 个视图 + 2 个流程态）
    ├── 概览（默认）
    ├── 扫描中（流程态）
    ├── 清理建议
    ├── 大文件
    ├── 排除列表
    ├── 清理进度（流程态）
    └── 完成（流程态）

导航规则：点击侧边栏项切换视图；当前项高亮（系统蓝浅底）；每页标题栏右上角提供「🔄 重新扫描」按钮（仅在已完成过扫描后显示）。

三、概览页

首次进入（未扫描状态）：

  • 大环形图呈灰色，中心显示「66.5% / 已使用 328.6 GB」（静态演示数据）
  • 分类瓦片区显示占位文案「点击开始智能扫描以获取可清理项分析」
  • 主操作：「✨ 开始智能扫描」大按钮 + 说明「只读扫描 · 不会改动任何文件 · 约 3 秒」

扫描范围切换（扫描按钮上方）：

  • 分段控件：🌐 全盘扫描（默认）/ 📁 指定目录
  • 切到「指定目录」展开目录编辑行：输入框（支持 ~ 路径）+「＋ 添加」按钮
  • 已添加目录显示为蓝色 chip（等宽字体），chip 上 × 可移除
  • 守卫逻辑：指定目录模式下未添加任何目录时，扫描按钮禁用并变为「⚠︎ 请先添加扫描目录」
  • 范围选择持久化，重开应用不丢失

分类瓦片（扫描完成后渲染）：每类显示彩色标识、名称、大小、项目数与属性标签（绿色「推荐清理」/ 橙色「需人工确认」）；点击瓦片跳转清理建议页。

环形图：扫描完成后由灰色变为按分类占比着色的分段环。

四、扫描流程

  1. 点击「开始智能扫描」→ 进入扫描中视图
  2. 进度环从 0% 匀速增长（约 3 秒），中心显示百分比；下方滚动显示当前扫描路径（指定目录模式下仅滚动范围内目录）；底部提示「正在以只读方式分析磁盘 · 范围：xxx · 已按排除列表跳过 N 个目录」
  3. 提供「取消」按钮，可随时中断返回概览
  4. 完成后 toast 提示：「扫描完成，发现 X 可清理空间（范围：…）· 已跳过 N 个排除目录」，自动跳转清理建议页
  5. 侧边栏「清理建议」「大文件」角标点亮，显示范围内实际项目数

五、清理建议页（核心交互）

5.1 分类卡片

  • 每类一张卡片：分类级复选框（圆形）、名称+属性标签、描述、大小、项目数、展开箭头
  • 点击卡片头部展开/收起文件明细列表（箭头旋转 90° 反馈）
  • 点击分类复选框 = 全选/全不选该分类；部分选中时复选框内显示已选数字

5.2 文件行

每行：行复选框（方形）｜图标｜文件名+完整路径｜未使用天数｜「🚫 排除」按钮｜大小。

  • 勾选：点击或 Space/Enter 键切换；选中项复选框变蓝打勾
  • 行内排除：悬停行时浮现「🚫 排除」按钮，点击将该文件所在目录加入排除列表，该文件立即从结果消失，分类大小/数量/汇总同步更新，toast 反馈「已排除目录 xxx，不再扫描」
  • 范围外或已排除的文件不渲染；空分类显示「当前扫描范围内无此分类的文件」

5.3 三级勾选联动

单文件勾选 → 分类勾选（显示部分选中数）→「全选推荐项」勾选，任一级操作实时向上/向下同步。

5.4 底部汇总栏

  • 勾选任意文件后从底部滑出（毛玻璃悬浮条）
  • 左侧：「全选推荐项」开关；中间：已选合计大小（大字）+ 已选项目数；右侧：「取消选择」「🗑 安全清理」按钮
  • 未选中任何项目时「安全清理」禁用

六、大文件页

  • 表格：复选框｜文件名｜位置｜修改时间（N 天前）｜大小（右对齐、等宽数字）
  • 按大小降序；悬停行高亮；支持多选
  • 底部汇总栏显示「已选 N 个大文件 · 合计 X」+「🗑 移入废纸篓」按钮（未选时禁用）
  • 范围外的大文件行隐藏，角标同步

七、排除列表页

  • 顶部说明：「以下目录在扫描时将被完全跳过，不计入可清理空间。规则自动保存，长期生效。支持通配符 *」
  • 添加行：路径输入框 +「＋ 加入排除」按钮（回车等效提交）
  • 规则列表：🚫 图标｜路径（等宽字体）｜来源备注（「默认锁定」「手动添加 · 刚刚」「来自清理建议 · 刚刚」）｜操作
  • 默认规则（系统目录 /System、com.apple.* 容器）预置且锁定，按钮显示「默认」并禁用，防止误删
  • 重复路径拦截提示「该路径已在排除列表中」；移除规则 toast「已移除排除规则，下次扫描生效」
  • 规则持久化，角标实时更新

八、清理确认弹窗

触发：清理建议页「🗑 安全清理」或大文件页「🗑 移入废纸篓」。

内容（自上而下）：

  1. 橙色警示图标 ⚠️ + 标题「确认清理这些文件？」
  2. 副标题：共 N 个项目 · 合计 X。将移入废纸篓（非彻底删除），可随时恢复
  3. 清单摘要（按分类/逐文件列出名称与大小，可滚动）
  4. 绿色信任背书行：「🗑 移入废纸篓 · 30 天内可恢复 · 不会立即释放磁盘」
  5. 底部双按钮：「取消」（灰）｜「移入废纸篓」（红字）

交互：弹窗淡入 + 缩放动画；点击遮罩或按 Esc 关闭；确认后进入清理进度。

九、清理进度与完成页

清理进度：

  • 渐变进度条匀速推进
  • 下方清单逐项显示本次处理的文件，完成一项点亮绿色 ✓（文件名由灰变黑）

完成页：

  • 绿色对勾图标（弹跳入场动画）+「清理完成」
  • 大字显示本次释放量「+X GB」
  • 说明文案：「所有文件已移入废纸篓，未从磁盘删除。清空废纸篓前可随时打开恢复；30 天后系统将自动彻底清除」
  • 双按钮：「↩︎ 撤销本次清理」（从废纸篓放回，结果页恢复原状并 toast 确认）｜「查看最新概览」（跳回概览页）

十、全局交互规范

维度规范
反馈所有增删改操作均有 toast 反馈（顶部居中滑入，2.6 秒自动消失）
键盘可达全部复选框/卡片/按钮支持 Tab 聚焦 + Space/Enter 激活；Esc 关闭弹窗
焦点可见focus-visible 蓝色焦点环，不因鼠标点击误触发
无障碍复选框带 role="checkbox" + aria-checked；图标按钮有 aria-label；弹窗 role="dialog" + aria-modal
动效统一 180ms 缓动；视图切换淡入上移；卡片悬停上浮 2px；不使用夸张动画
数字容量/计数一律等宽数字（tabular-nums），避免跳动
响应式≤760px 隐藏侧边栏，单栏布局
持久化排除列表（cleandisk_excludes_v1）与扫描范围（cleandisk_scope_v1）写入 localStorage；勾选状态为会话级，不持久化

十一、核心状态流转

概览（未扫描）
   │ 点击「开始智能扫描」
   ▼
扫描中 ──取消──▶ 概览
   │ 完成（自动）
   ▼
清理建议 ◀──导航──▶ 大文件 / 排除列表 / 概览
   │ 勾选 → 点「安全清理」
   ▼
确认弹窗 ──取消──▶ 返回原页
   │ 确认
   ▼
清理进度 ──完成──▶ 完成页 ──撤销──▶ 清理建议（恢复原状）
                └─查看概览─▶ 概览（可重新扫描）

范围与排除的叠加关系：实际扫描范围 = 指定目录（若启用）∩ 未命中排除规则；两级过滤在扫描完成时统一计算，结果页、角标、汇总口径完全一致。

十二、原型边界说明

  1. 文件/目录数据为演示数据（Demo fixture），非真实磁盘内容；扫描动画为模拟
  2. 指定目录的路径匹配采用「~ 展开 + 前缀匹配」的简化实现；正式实现建议基于文件系统遍历
  3. 「清理」在原型中仅更新视觉状态（行灰显/移除），磁盘数字保持不变——如实模拟废纸篓语义
  4. 通配符匹配（*）在原型中仅作规则文案展示，未实现匹配引擎
  5. localStorage 数据可在浏览器开发者工具中清除以重置演示状态
